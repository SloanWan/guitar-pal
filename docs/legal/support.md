# Support

Guitar Pal is run by one person, Sloan Wan. For help, bug reports, feedback or
a request about your data, email
[nysuswan@gmail.com](mailto:nysuswan@gmail.com). Say which page you were on
and what you expected, and attach a screenshot if you can.

## Reporting a security problem

If you find a security vulnerability, email
[nysuswan@gmail.com](mailto:nysuswan@gmail.com) with **Security** in the
subject: what you found, how to reproduce it, and what it affects. Please do
not make it public, or test it against other people's accounts or data, until
it has been fixed. Every report is read and answered.

## The AI connector (MCP)

How to add Guitar Pal to Claude, ChatGPT, Cursor or VS Code is on
[Connect Guitar Pal to your AI](/docs/mcp). If it does not work:

- **The app does not use Guitar Pal.** Name it in the request ("Use Guitar Pal
  to…"). In ChatGPT, type `@` and pick Guitar Pal; in Claude, check the
  connector is on under **+ → Connectors** for that chat.
- **ChatGPT has no Add custom MCP server button.** It needs ChatGPT Plus or a
  higher plan, and adding works on the web only.
- **A tool answers that it is over a limit.** Wait for the time it gives and try
  again.
- **A link no longer opens.** Links made through the connector expire after 30
  days; ask again for a new one.
- **A tab read from an image is wrong.** Check the places listed under the
  title against the original, and fix them in the editor after **Import**.

## Your data

To delete your data or your account, use **Settings → Delete**. For anything
else, see the [privacy policy](/privacy) or email
[nysuswan@gmail.com](mailto:nysuswan@gmail.com).
