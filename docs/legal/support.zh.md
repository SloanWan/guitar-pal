## 报告安全问题

如果你发现了安全漏洞，请写信到 [nysuswan@gmail.com](mailto:nysuswan@gmail.com)，标题里写上 **Security**，说明你发现了什么、怎样复现、影响到什么。在修复之前，请不要公开，也不要拿别人的账号或数据做测试。每份报告都会被阅读并回复。

## AI 连接器（MCP）

怎样把 Guitar Pal 加进 Claude、ChatGPT、Cursor 或 VS Code，见[把 Guitar Pal 接入你的 AI](/docs/mcp)。如果用不起来：

- **AI 应用没有用 Guitar Pal。** 在请求里点名（"用 Guitar Pal……"）。在 ChatGPT 里输入 `@` 选中 Guitar Pal；在 Claude 里，确认这个对话的 **+ → Connectors** 里已经打开它。
- **ChatGPT 里没有 Add custom MCP server 按钮。** 需要 ChatGPT Plus 或更高的订阅，并且只能在网页版添加。
- **工具回复说超出了限制。** 按它给的时间等一会儿再试。
- **链接打不开了。** 通过连接器生成的链接 30 天后失效，重新让它生成一个即可。
- **从图片读出的谱不对。** 对照原谱检查标题下面列出的位置，点 **Import** 后在编辑器里修改。
