# WebAudioFont presets

The `.json` files here are instrument presets from
[surikov/webaudiofontdata](https://github.com/surikov/webaudiofontdata),
converted from its JavaScript files to JSON on 2026-10-22 by
`scripts/convert-webaudiofont-presets.mjs` in the Guitar Pal repository. The
content is unchanged; only the file format differs.
